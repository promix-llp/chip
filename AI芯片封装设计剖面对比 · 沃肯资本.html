A · 2.5D 并列封装 — 存储与计算「肩并肩」放在硅中介层上

计算 Die 与 HBM 堆栈并排坐落在 硅中介层 (Si Interposer) 上，靠中介层里的高密度布线横向连接。这是英伟达与谷歌的主流方案：带宽极高，但中介层 + CoWoS 封装成本占整芯片约 1/3，且依赖台积电 CoWoS 产能与 HBM 供应。

B · 近存计算 + 有机基板（绕开 CoWoS）— 存储单元内置计算，告别硅中介层

两者共同点：存储单元的 base die 内置计算（而非 HBM base die 只做 SerDes 数传），且用有机基板替代硅中介层 / CoWoS，大幅降低封装成本。差异在空间排布——d-Matrix 把 DRAM 垂直堆叠在计算 chiplet 上方（3D）；艾捷科芯二代则把 6 颗含计算的 Memory Cube 平铺封装在 GPU 周围（类 2.5D 摆位）。由于计算在存储侧完成，二者对外部带宽的需求都显著低于 HBM 方案。

C · 单片集成 — 计算与存储在「同一片硅」上，无外部内存、无堆叠

不使用外部 HBM、不做 die 堆叠，存储与计算融合在同一颗单片 Die 内。Groq 用片上 SRAM 做数据流；后摩把乘加做进 SRAM 单元；亿铸用 ReRAM 交叉阵列。封装最简单、成本最低，但片上容量受限，难承载超大模型。

剖面图说明：所有剖面为结构示意，层数 / 凸点数量为表意性简化，非真实物理尺寸比例。Rubin / TPU 的 HBM 堆栈实际为 8–16 层（剖面仅示部分）；艾捷科芯二代「6 颗含计算 Memory Cube 平铺于 GPU 周围 + 多制程（base die 14nm / 上层 4/5nm）+ 有机基板替代 CoWoS」为访谈所述设计方案，2027 H1 流片后方可验证。d-Matrix 3DIMC 已在 Pavehawk 测试硅上验证。
